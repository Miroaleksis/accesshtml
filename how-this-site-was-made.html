How This Site Was Made

About the author

The author of this website is an accessibility specialist from Finland. Inspired by the problems they encounter in their daily work, they created this website to help users avoid common acceesibility shortcomings. Where many of the same generic issues recur across different websites. It offers practical help for implementing common web patterns accessibly, so that these issues can be avoided from the start.

How the site was built and reviewed

The site is built in the spirit of its subject, with plain HTML, CSS and JavaScript.

Use of AI

AI tools were used to streamline the development process. All contents on the site have been written, reviewed, or edited by the author. The author is responsible for the content.

Sources

The information provided by this website is based on the expertise of the author and the following sources (mostly but not limited to):

  • Web Content Accessibility Guidelines (WCAG) 2.2
  • WAI-ARIA Authoring Practices Guide
  • MDN Web Docs
