How This Site Was Made

Background

The topics covered on this website are drawn from common accessibility issues that specialists encounter in their daily work when auditing websites. The site was created to help users fix existing accessibility issues and avoid common shortcomings when creating new content. A challenge the site also aims to address is that accessibility guides often delve deeply into technical details or theoretical concepts and may require significant expertise or time to interpret. The site aims to be easily scannable and provide practical guidance quickly without overwhelming the user.

How the Site Was Built and Reviewed

The site is built in the spirit of its subject, with plain HTML, CSS and JavaScript. The accessibility status of the site and the web patterns demonstrated on it has been reviewed using the methods listed in the Accessibility Statement.

AI disclaimer: AI tools were used when building this website to assist the development process. However, all content presented has been written, reviewed or edited by the author. The author is responsible for the content.

Sources

The information provided by this website is based on the expertise of the author and the following external sources, among others:

  • Accessible Rich Internet Applications (WAI-ARIA) 1.2
