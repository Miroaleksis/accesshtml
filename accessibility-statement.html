Accessibility Statement

The purpose of this statement is to describe the accessibility status of AccessHTML.com and its contents. The statement outlines the possible known issues in the accessibility of the service and provides instructions on how to send feedback or improvement suggestions. The description of the site's accessibility is based on self-assessment of an accessibility specialist and peer reviews.

Review methods

The accessibility status of the site has been reviewed with the following methods:

  • Code inspection: manual and automated checks for technical errors
  • Keyboard testing: use without a pointer
  • Screen reader testing: use with hearing alone
  • Gesture testing: use without dragging or other fine motor gestures
  • Adaptability testing: readability when content is enlarged, modified, or displayed on different screen sizes and orientations
  • Sensory evaluation: perceivability by sight and hearing
  • Understandability evaluation: clarity of language, instructions and predictability

Accessibility status

The service fully complies with the accessibility requirements set out in the Web Content Accessibility Guidelines (WCAG) 2.2, Level AA.

Non-accessible content

The website does not claim conformance with WCAG 2.2 Level AAA, so some content may not meet its requirements.

A note about the use of ARIA: the lists of accessibility features use aria-description to communicate whether a feature is required or recommended. The attribute is not yet supported by all assistive technologies.

Embedded and special content

The pattern pages contain code examples that demonstrate accessible HTML. The examples are part of the website and are assessed together with its other content.
